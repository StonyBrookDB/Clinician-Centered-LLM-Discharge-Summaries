# Demo Data Folder

This folder starts with small CSV files for the fabricated demo.

- `doctor_info.csv` lists local users.
- `review_assignments.csv` says which encounter each user reviews.
- `incidental_findings.csv` lists optional findings for the incidental findings tab.
- `reviews.db` is generated by setup and stores ratings, comments, highlights, and annotations.
- `raw/` is generated by setup and stores encrypted encounter files used by the app.

Do not commit real patient data, real clinician accounts, real credentials, or a real review database.
